ESTADO DE ACOPLAMIENTOS LCO - APLICACION INDEPENDIENTE
======================================================

REQUISITO
La PC debe tener Node.js LTS instalado: https://nodejs.org/

COMO INICIAR
1. Extraiga toda la carpeta del archivo ZIP.
2. Haga doble clic en "Iniciar Acoplamientos LCO.bat".
3. La aplicacion se abrira en el navegador predeterminado.
4. Mantenga abierta la ventana negra mientras utiliza la aplicacion.

DATOS
- Los controles, recambios, configuracion y fotos se guardan en el navegador de esta PC.
- Use "Guardar respaldo" regularmente. El archivo .lcocouplings permite restaurar toda la aplicacion, incluidas las fotos.
- Use "Exportar Excel" para obtener una copia legible, ordenable e imprimible del estado actual y del historial.
- Conserve ambos archivos: el respaldo sirve para recuperar el sistema y el Excel para consultar la informacion sin instalar la aplicacion.
- Para trasladar los datos a otra PC, exporte el respaldo e importelo en la nueva instalacion.
- No borre los datos del navegador sin haber realizado antes un respaldo.

CIERRE
Presione Ctrl+C en la ventana negra o cierre esa ventana.
